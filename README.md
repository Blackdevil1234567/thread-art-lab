## 🌟 Overview

**Thread Art Lab** is a web-based creative application that transforms photos and custom artwork into physical string art patterns. Using image processing, customizable pin layouts, and color palette algorithms, Thread Art Lab generates step-by-step thread routing instructions and downloadable PDF guides for crafters and artists.

---

## ✨ Key Features

- 🖼️ **Image Processing & Upload**: Upload photos or vector artwork to generate string art representations.
- 🎨 **Palette & Color Customization**: Customize thread colors, contrast levels, pin counts, and thread density.
- 🧵 **Pattern Generation Engine**: Real-time algorithm calculates optimal pin-to-pin thread paths.
- 📄 **Export & PDF Blueprint**: Export canvas renders and step-by-step PDF assembly instructions.
- ⚡ **Modern Interactive UI**: Built with shadcn/ui, Radix UI Primitives, and Tailwind CSS.

---

## 🛠️ Tech Stack

- **Frontend Framework**: React 18 + Vite
- **Language**: TypeScript
- **Canvas Rendering**: Fabric.js v6.7
- **UI Components**: shadcn/ui, Radix UI, Lucide Icons, Sonner Toasts
- **Styling**: Tailwind CSS
- **Export Utility**: html2canvas, jsPDF
